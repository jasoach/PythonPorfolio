Tortoise and Hare Race Simulation
This project simulates the classic “Tortoise vs. Hare” race using Python and random number generation. The tortoise and hare move forward based on probabilistic rules, and the simulation runs thousands of races to determine how often each competitor wins. The results provide insight into how randomness and sleep behavior affect outcomes.
Randomized Movement Logic — Each racer advances using random step sizes, creating unpredictable race outcomes.

Hare Sleep Mechanic — The hare has a chance to fall asleep each turn, adding strategy and variability.

Large‑Scale Simulation — Runs 100,000 races to gather meaningful win/loss/tie statistics.

Clear Output — Displays total wins for the tortoise, hare, and ties for easy interpretation.

Easy to Modify — Adjustable finish line, movement ranges, and sleep probability.

Password Protection Program
This project analyzes the top 500 most common passwords and helps users understand the risks of weak password choices. By pulling data from a CSV file, the program allows users to check password rankings, evaluate password strength, and estimate how long it would take to crack a given password. It serves as an educational tool to promote better cybersecurity habits.

Password Ranking Lookup — Users can enter a rank (1–500) to see which password holds that position in popularity.

Strength & Crack‑Time Analysis — Evaluates a password’s strength score and estimates how long it would take to crack based on dataset metrics.

Top 10 Passwords — Quickly displays the ten most commonly used passwords for awareness and comparison.

Weak vs. Strong Detection — Determines whether a password is considered strong based on its assigned strength score.

Interactive Menu System — A user‑friendly text menu allows easy navigation between all available features.

CSV‑Driven Data — Reads from a real dataset of 500 passwords, including rank, category, strength, and estimated crack time.

Linear and Binary Search Comparison

This project demonstrates the dramatic performance difference between linear search and binary search when attempting to guess a secret number. A random number between 1 and 1 trillion is generated, and each algorithm attempts to find it. The simulation highlights how binary search reduces the number of guesses from billions to around 40 steps, showcasing the power of divide‑and‑conquer algorithms.

Random Number Generation — Creates a secret number in a massive range (1–1,000,000,000,000) to stress‑test both algorithms.

Linear Search Demonstration — Shows how a simple sequential search becomes extremely inefficient at large scales.

Binary Search Algorithm — Efficiently narrows the search space by halving the range each step.

Performance Comparison — Prints how many attempts each algorithm takes, making the difference easy to understand.

Slot Machine Simulation
This project simulates a simple slot machine game where players deposit virtual currency (“nolan coins”), spin the reels, and win or lose based on randomized outcomes. Each spin generates three symbols with weighted probabilities, creating realistic slot‑machine behavior. The program includes both an interactive mode and an automated simulation to test long‑term outcomes.

Weighted Random Spins — Uses probability weights to make certain symbols more or less likely, mimicking real slot machines.

Jackpot & Match Rewards — Triple 7s award a large jackpot, while matching other symbols gives smaller rewards.

Virtual Currency System — Players can deposit, view funds, spin (costing 10 coins), and cash out.

Interactive Menu — A simple text‑based interface lets users choose actions like spinning or depositing.

Automated Simulation Mode — Runs 1,000 spins automatically to observe expected long‑term winnings or losses.

Beginner‑Friendly Structure — Clear functions (spin, cont, simulation) make the program easy to understand and modify.

Word Counter
The Word Counter is a simple Python utility that calculates how many words appear in a given text input. It’s designed to be lightweight, easy to understand, and perfect for beginners learning about string manipulation. The function splits text into individual words and returns an accurate count based on whitespace separation.
Accurate Word Counting — Uses Python’s built‑in string methods to reliably count words.

Beginner‑Friendly Code — Clear variable names and simple logic make it easy to learn from.

Instant Output — Prints the total word count immediately for quick feedback.

Easy to Extend — Can be expanded to handle punctuation, unique words, or file input.
